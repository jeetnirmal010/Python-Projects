# 🧮 Advanced Calculator

A menu-driven calculator built using Python.

## Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🚫 Division by zero protection
- 🔁 Continuous menu using `while True`
- ❌ Exit option

## Technologies

- Python 3

## How to Run

```bash
python main.py
```
