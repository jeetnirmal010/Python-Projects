# 📚 Library Management System

A simple menu-driven Library Management System built using Python. This project allows users to manage books by adding, viewing, searching, updating, deleting, and viewing a library summary.

---

## 🚀 Features

- ➕ Add Book
- 📖 View All Books
- 🔍 Search Book
- ✏️ Update Book Details
- 🗑️ Delete Book
- 📊 Show Library Summary
- ❌ Exit Program

---

## 🛠️ Technologies Used

- Python 3
- Lists
- Dictionaries
- Loops
- Conditional Statements
