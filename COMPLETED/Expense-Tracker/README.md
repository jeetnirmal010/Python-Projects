# 💰 Expense Tracker

A simple Python console application that helps users record their expenses, view all expenses, and calculate the total amount spent.

## 📌 Features

- ➕ Add new expenses
- 📋 View all recorded expenses
- 💰 Calculate the total amount spent
- 📊 Menu-driven interface
- ❌ Exit the application

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run:

```bash
python main.py
```
