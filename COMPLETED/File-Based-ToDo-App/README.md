# ✅ File-Based To-Do App

A simple Python console application that lets users save and view tasks using a text file.

## 📌 Features

* ➕ Add new tasks
* 📋 View all saved tasks
* 💾 Stores tasks in a text file (`tasks.txt`)
* 🔄 Menu-driven interface
* ❌ Exit option

## 🛠️ Technologies Used

* Python 3
* File Handling

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run:

```bash
python main.py
```
