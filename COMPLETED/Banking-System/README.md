# 🏦 Banking System (Python)

A simple command-line Banking System built using Python. This project allows users to create and manage bank accounts using lists, dictionaries, loops, and conditional statements.

## 🚀 Features

- ✅ Create a new bank account
- ✅ View all accounts
- ✅ Search an account by account number
- ✅ Deposit money
- ✅ Withdraw money
- ✅ Delete an account
- ✅ Display bank summary

## 📋 Account Information

Each account stores:

- Account Number
- Account Holder Name
- Account Type (Saving / Current)
- Balance

## 📊 Bank Summary

The summary displays:

- Total number of accounts
- Total money in the bank
- Average account balance
- Account holder with the highest balance
- Highest balance amount

## 🛠 Concepts Used

- Python Lists
- Python Dictionaries
- While Loops
- For Loops
- Conditional Statements (`if`, `elif`, `else`)
- CRUD Operations
- Input Validation
- Searching
- Data Aggregation

## ▶️ How to Run

1. Install Python 3.
2. Save the file as `banking_system.py`.
3. Open a terminal.
4. Run:

```bash
python banking_system.py
```
