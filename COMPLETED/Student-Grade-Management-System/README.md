# 🎓 Student Grade Management System (Python)

A simple command-line Student Grade Management System built using Python. This project demonstrates CRUD (Create, Read, Update, Delete) operations using lists, dictionaries, loops, functions, and conditional statements.

## 🚀 Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student by ID
- ✏️ Update Student Record
- ❌ Delete Student Record
- 📊 Show Class Summary
- 🏆 Automatic Grade Calculation

## 📚 Student Information

Each student record stores:

- Student ID
- Student Name
- Subject 1 Marks
- Subject 2 Marks
- Subject 3 Marks
- Total Marks
- Percentage
- Grade

## 📝 Grade System

| Percentage | Grade |
|------------|-------|
| 90+ | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| Below 60 | F |

## 📊 Class Summary

The program displays:

- Total Students
- Average Percentage
- Highest Scorer
- Lowest Scorer
- Grade A Students
- Grade B Students
- Grade C Students
- Grade D Students
- Grade F Students
