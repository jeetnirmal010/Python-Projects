# 📊 Grade Calculator

A simple Python application that calculates and displays a student's grade based on their score.

## 📌 Features

* 👤 Accepts the student's name
* 📝 Accepts the student's score
* ✅ Validates that the score is between **0 and 100**
* 🏆 Assigns grades:

  * **A** → 90–100
  * **B** → 75–89
  * **C** → 60–74
  * **F** → Below 60
* 📋 Displays a clean report card

## 🛠️ Technologies Used

* Python 3

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run:

```bash
python main.py
```
