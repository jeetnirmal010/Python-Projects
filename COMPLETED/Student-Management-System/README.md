# 🎓 Student Management System

A menu-driven Python application for managing student records.

## 📌 Features

- ➕ Add Student
- 📋 View Students
- 🔍 Search Student
- ❌ Exit Program

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

```bash
python main.py
```

## 📷 Example

```
====== STUDENT MANAGEMENT SYSTEM ======

1. Add Student
2. View Students
3. Search Student
4. Exit
```

## 📚 Concepts Practiced

- Lists
- Dictionaries
- Loops
- Functions
- Searching
- Conditional Statements
- Menu-Driven Programs
