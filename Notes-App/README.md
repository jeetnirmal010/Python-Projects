# 📝 Notes App

A simple Python application that allows users to write a note, save it to a file, and read it back.

## 📌 Features

* ✍️ Accepts a note from the user
* 💾 Saves the note to a text file (`my_notes.txt`)
* 📖 Reads and displays the saved note
* 🖥️ Simple console-based application

## 🛠️ Technologies Used

* Python 3
* File Handling

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run:

```bash
python main.py
```

## 📷 Example Output

```text
Enter a note: Learn Python every day

Saved Note:
Learn Python every day
```
