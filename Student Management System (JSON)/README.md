# 🎓 Student Management System (JSON)

A simple command-line **Student Management System** built using **Python** and **JSON** for data storage.

This project demonstrates CRUD (Create, Read, Update, Delete) operations without using a database.

---

## 📌 Features

* ➕ Add Student
* 📋 View All Students
* 🔍 Search Student by Roll Number
* ✏️ Update Student Details
* 🗑️ Delete Student
* 💾 Automatic Data Saving
* 📂 Automatic Data Loading
* 🚫 Duplicate Roll Number Validation
* ⚠️ Exception Handling for Invalid Input
