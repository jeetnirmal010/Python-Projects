# 🏦 Banking Management System

A simple Banking Management System built with Python using file handling. This project allows users to create and manage bank accounts through a menu-driven interface.

---

## 📌 Features

- ✅ Create New Account
- ✅ View All Accounts
- ✅ Search Account
- ✅ Deposit Money
- ✅ Withdraw Money
- ✅ Update Account Details
- ✅ Delete Account
- ✅ Data Stored Using File Handling

---

## 📂 Project Structure

```
Banking-Management-System/
│
├── main.py
├── accounts.txt
└── README.md
```

---

## 💾 Data Storage

Account records are stored in **accounts.txt**.

Each account is saved in the following format:

```
AccountNumber,CustomerName,PhoneNumber,Balance,AccountType
```

Example:

```
acc101,John,9876543210,1500.0,Savings
```

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```
