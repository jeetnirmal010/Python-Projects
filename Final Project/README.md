# 💰 Expense Tracker

A full-stack Expense Tracker web application built with Python, Flask, SQLite, HTML, CSS, and JavaScript.

This project allows users to record, manage, search, filter, analyze, and export their expenses.

---

## 🚀 Features

- Add expenses
- View expense details
- Edit expenses
- Delete expenses
- Delete confirmation
- Form validation
- Search expenses by title or category
- Filter by minimum amount
- Filter by maximum amount
- Filter by date range
- Clear search filters
- Calculate total expenses
- Count total records
- Calculate spending by category
- Calculate monthly spending
- Category spending pie chart
- Monthly spending line chart
- Export expenses to CSV
- SQLite database
- Responsive dashboard
- Flash messages for validation and errors
