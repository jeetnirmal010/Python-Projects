# 📦 Inventory Management System

A simple Inventory Management System built using Python. This project allows users to manage products through a menu-driven interface.

## 🚀 Features

- ➕ Add Product
- 📋 View All Products
- 🔍 Search Product
- ✏️ Update Product
- 🗑️ Delete Product
- 📊 Show Inventory Summary
- ❌ Exit Program

## 🛠️ Technologies Used

- Python 3
- Lists
- Dictionaries
- Loops
- Conditional Statements

## 📂 Project Structure

```
│
├── main.py

```

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/jeetnirmal010/Python-Projects.git
```

2. Navigate to the project folder:

```bash
cd Python-Projects/Inventory-Management-System
```

3. Run the program:

```bash
python main.py
```
