# 🎓 Student Grade Management System

A simple command-line Student Grade Management System built with Python.

This project allows users to manage student records using file handling. All student data is stored in a text file (`student.txt`).

---

## 🚀 Features

- Add Student
- View All Students
- Search Student by ID
- Update Student Record
- Delete Student Record
- Show Class Summary
- Automatic Grade Calculation
- File-based Data Storage

---

## 📚 Technologies Used

- Python 3
- File Handling
- Lists
- Dictionaries
- Loops
- Conditional Statements
- Functions

## 🎯 Grading System

| Percentage | Grade |
|------------|-------|
| 90 - 100 | A |
| 80 - 89 | B |
| 70 - 79 | C |
| 60 - 69 | D |
| Below 60 | F |

## ▶️ How to Run

1. Install Python 3.
2. Download this project.
3. Open a terminal.
4. Run:

```bash
python student_grade_management_system.py
```
