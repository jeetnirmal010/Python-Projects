# 🏦 Banking Management System (Python OOP)

A console-based Banking Management System developed using **Python**, **Object-Oriented Programming (OOP)**, and **File Handling**.

This project simulates a basic banking application where users can create accounts, perform transactions, and generate reports.

---

# 🚀 Features

## Account Management

- Open New Account
- View All Accounts
- Search Account
- Update Account Details
- Close Account

---

## Transaction Management

- Cash Deposit
- Cash Withdrawal
- Fund Transfer
- Automatic Transaction History

---

## Balance Inquiry

- Check Current Account Balance

---

## Statement of Account

- View Complete Transaction History
- Opening Balance
- Deposits
- Withdrawals
- Fund Transfers
- Closing Balance

---

## Reports

- Total Active Accounts
- Total Closed Accounts
- Total Bank Balance
- Total Transactions
