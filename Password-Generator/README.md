# 🔐 Password Generator

A simple Python application that generates strong random passwords based on the user's preferences.

## 📌 Features

- 🔢 Choose password length
- 🔤 Include letters
- 🔢 Include numbers
- 🔣 Include symbols
- 🔄 Generate multiple passwords without restarting
- ✅ Input validation
- ❌ Exit anytime

## 🛠️ Technologies Used

- Python 3
- random module
- string module

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run:

```bash
python main.py
```
