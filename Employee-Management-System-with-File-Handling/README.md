# 👨‍💼 Employee Management System (Python)

A command-line Employee Management System built using Python. This project demonstrates CRUD operations, file handling, searching, updating, and data management using Python lists.

---

## 🚀 Features

- ✅ Add Employee
- ✅ View All Employees
- ✅ Search Employee by ID
- ✅ Update Employee Details
- ✅ Delete Employee
- ✅ Increase Employee Salary by Percentage
- ✅ View Employee with Highest Salary
- ✅ View Department-wise Employees
- ✅ Store Employee Records in File
- ✅ Automatically Load Data on Program Start

---

## 📋 Employee Information

Each employee record stores:

- Employee ID
- Employee Name
- Employee Age
- Gender
- Department
- Designation
- Salary
- Contact Number

4. Run:

