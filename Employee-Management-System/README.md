# 👨‍💼 Employee Management System

A simple menu-driven Employee Management System built using Python. This project allows users to manage employee records by adding, viewing, searching, updating, deleting, and displaying employee summary statistics.

---

## 🚀 Features

- ➕ Add Employee
- 👥 View All Employees
- 🔍 Search Employee by ID
- ✏️ Update Employee Details
- 🗑️ Delete Employee
- 📊 Show Employee Summary
- ❌ Exit Program

---

## 🛠️ Technologies Used

- Python 3
- Lists
- Dictionaries
- Loops
- Conditional Statements
