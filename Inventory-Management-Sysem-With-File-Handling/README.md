# 📦 Inventory Management System (Python)

A simple command-line Inventory Management System built using Python and File Handling. This project helps manage product inventory by allowing users to add, update, search, delete, purchase, and sell products while storing all data in a text file.

---

## 🚀 Features

- ✅ Add New Product
- ✅ View All Products
- ✅ Search Product by Product ID
- ✅ Update Product Details
- ✅ Delete Product
- ✅ Purchase Stock
- ✅ Sell Stock
- ✅ View Low Stock Products
- ✅ View Highest Stock Product
- ✅ Category Wise Product View
- ✅ Inventory Summary
- ✅ Automatic File Saving
- ✅ Automatic Data Loading

---

## 📋 Product Information

Each product stores:

- Product ID
- Product Name
- Category
- Brand
- Buying Price
- Selling Price
- Quantity
- Supplier Name

---

## 📊 Inventory Summary

The system displays:

- Total Products
- Total Quantity
- Total Inventory Cost
- Expected Revenue
- Total Profit

---

## 📁 File Handling

All product records are stored inside:

```text
Inventory.txt
```

The program automatically:

- Loads records when the program starts.
- Saves records after every change.

## ▶️ How to Run

1. Install Python 3.
2. Download the project.
3. Open the project folder.
4. Run:

```bash
python main.py
```
