# 🏥 Hospital Management System (Python)

A simple **Hospital Management System** built using **Python** and **File Handling**.

This project allows users to manage patient records through a menu-driven interface while storing data permanently in a text file.

---

## ✨ Features

* ➕ Add New Patient
* 📋 View All Patients
* 🔍 Search Patient by ID
* ✏️ Update Patient Details
* 🗑️ Delete Patient Record
* 💾 Automatic File Saving
* 📂 Persistent Data Storage using `patients.txt`
