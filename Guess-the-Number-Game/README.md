# 🎮 Guess the Number Game

A fun Python console game where the computer randomly selects a number, and the player tries to guess it.

## 📌 Features

* 🎲 Generates a random number between **1 and 10**
* ⌨️ Accepts user guesses
* 📉 Displays **"Too low!"** if the guess is smaller
* 📈 Displays **"Too high!"** if the guess is larger
* 🎉 Congratulates the player when they guess correctly
* 🔢 Counts the number of attempts

## 🛠️ Technologies Used

* Python 3
* `random` module

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run:

```bash
python main.py
```
